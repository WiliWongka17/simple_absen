PRD — SISTEM ABSENSI SISWA BERBASIS WEB
1. INFORMASI PROYEK

Nama proyek:
Sistem Absensi Siswa Berbasis Web

Tujuan:
Membuat sistem absensi siswa yang ringan, sederhana, mudah digunakan, dan tidak memerlukan instalasi aplikasi di HP siswa.

Stack teknologi:

Frontend / Application: Next.js
Backend dan Database Service: Supabase
Database: PostgreSQL
Hosting: Vercel
Bahasa: TypeScript
Styling: Tailwind CSS
QR Code: library QR Code yang kompatibel dengan Next.js
GPS: Browser Geolocation API

Target pengguna:

Siswa
Guru
Admin sekolah

Prinsip utama:

Siswa tidak perlu membuat akun.
Siswa tidak perlu menginstal aplikasi.
Siswa cukup scan QR Code menggunakan kamera HP/browser.
Siswa memasukkan NIS.
Sistem memvalidasi lokasi siswa menggunakan GPS.
Absensi hanya valid jika siswa berada dalam radius sekolah.
Sistem harus ringan dan sederhana.
Jangan menggunakan Laravel.
Jangan membuat aplikasi Android/iOS native.

QR Code tidak boleh langsung berisi:

NIS
data pribadi siswa
status absensi

Contoh:

https://domain-sekolah.com/absen?token=TOKEN

Token harus divalidasi oleh server.

REKOMENDASI:

Gunakan QR Code dinamis.

Token memiliki:

nilai token acak
waktu mulai
waktu kedaluwarsa
status aktif

Contoh konsep:

attendance_sessions

id
token
start_time
expires_at
is_active

Token harus dibuat menggunakan nilai acak yang aman.

Jangan menggunakan:

timestamp sederhana sebagai token
NIS sebagai token
nama sekolah sebagai token

school_longitude
attendance_radius

Contoh:

school_latitude = -8.xxxxx
school_longitude = 115.xxxxx
attendance_radius = 100

meter.

longitude

12. VALIDASI GPS

Contoh aturan awal:

100 meter

accuracy maksimum:
100 meter

Catatan:
Nilai tersebut harus dibuat configurable.

Jangan hardcode radius di frontend.

Server harus melakukan:

Jika distance <= configured_radius:
lokasi valid

Jika distance > configured_radius:
lokasi tidak valid
